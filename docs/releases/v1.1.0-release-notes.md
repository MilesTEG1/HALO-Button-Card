# 🏷️ Guide de Release & Notes de Version — v1.1.0

Ce document récapitule les consignes opérationnelles pour publier la release **v1.1.0** sur GitHub ainsi que le texte de description à coller dans l'interface de publication.

---

## 🚀 1. Consignes Opérationnelles (Terminal)

Exécute ces commandes dans ton terminal (avec ton agent SSH actif) :

```bash
cd /home/pili-debian/workspace-IDA-antigravity/Forgejo-GitHub-Antigravity/HALO-Button-Card

# Étape A : Fusion automatique de Antigravity-LLM vers main avec signature locale (-S)
sghy

# Étape B : Création du tag v1.1.0 signé
git tag -s -a v1.1.0 main -m "[Antigravity] release: v1.1.0 HALO-Button-Card - custom:halo-light-card & UI Editor"

# Étape C : Poussée du tag vers Forgejo (réplication automatique vers GitHub)
git push origin v1.1.0
```

---

## 🌐 2. Publication sur GitHub

1. Accède à l'interface GitHub : **[Releases — HALO-Button-Card](https://github.com/MilesTEG1/HALO-Button-Card/releases)**
2. Clique sur **« Draft a new release »**.
3. Renseigne :
   - **Tag version :** `v1.1.0`
   - **Target :** `main`
   - **Release title :** `v1.1.0 — Introduction de custom:halo-light-card & Éditeur Visuel UI`
4. Colle le texte Markdown ci-dessous dans la zone principale.
5. *(Recommandé)* Glisse-dépose le fichier `dist/halo-button-card.js` dans la zone de pièces jointes.
6. Clique sur **« Publish release »**.

---

## 📝 3. Texte Markdown de la Release GitHub (à copier-coller)

```markdown
# 🌟 HALO-Button-Card v1.1.0

Cette version majeure introduit le composant unifié pour l'éclairage **`custom:halo-light-card`**, son éditeur visuel complet `<ha-form>`, ainsi que des ajustements stylistiques de haute précision pour une intégration parfaite dans l'écosystème de tableaux de bord **HOLM**.

---

## 💡 Nouveautés majeures

### 1. Nouveau composant `custom:halo-light-card`
- **Architecture native LitElement** : Rendu `Persistent DOM` ultra-performant, réactivité instantanée et zéro scintillement.
- **Disposition HOLM unifiée (`tuile_avec_sous_boutons`)** :
  - **Zone principale** : Nom de la pièce/luminaire, état textuel en direct et icône dynamique avec état marche/arrêt distinct.
  - **Curseur Liquid Glass intégré** : Slider fluide (0 à 100 %) superposé avec verre dépoli et retour d'état en temps réel. S'efface proprement si la lampe est un simple relais On/Off.
  - **Halo spéculaire dynamique 16 teintes** : Calé en temps réel sur la couleur émise (RGB / Température de couleur) ou sur une teinte prédéfinie.
  - **Trio de sous-boutons compacts à droite** :
    - 🔆 Variateur / luminosité rapide.
    - 🌡️ Température de couleur (chaleur).
    - ⚡ Interrupteur principal marche/arrêt (Toggle).
- **Calibrage au pixel près** : Hauteur constante normalisée à **64 px** et centrage vertical des icônes pour un alignement rigoureux avec `custom:halo-cover-card` en vue `sections` ou `grid`.

### 2. Éditeur Visuel Intégré (`<ha-form>`)
- Configuration 100 % graphique depuis l'interface Lovelace (aucun YAML requis).
- Sélecteur d'entités `light.*`.
- Sélecteur chromatique complet (roue 2D et nuancier 16 couleurs).
- Gestion des noms personnalisés, options d'affichage et retours tactiles/haptiques.

### 3. Ajustements de `custom:halo-separator-card`
- Équilibrage des marges, de l'épaisseur du trait cyan et de l'intensité du halo lumineux pour s'harmoniser fidèlement avec les chartes de design sombres.

---

## 📦 Artefacts & Distribution
- **Bundle lisible et aéré** : `dist/halo-button-card.js` (bundle Rollup non minifié de 2 470 lignes pour une lisibilité et un débogage optimaux).
- **Documentation complète bilingue** : `README.md` et `README.fr.md`.
- **Wiki autonome et captures réelles** : Guide didactique et captures d'écran haute définition intégrés sous `docs/wiki/`.
```
